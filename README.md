# OBLIGARIADO
Pagina Web Escuela
Plataforma educativa interactiva para niños de grado 0 a 5 de primaria.

El objetivo de esta página es enseñar diferentes temas educativos mediante:

- teoría sencilla
- ilustraciones
- videos
- juegos interactivos
- mini quizzes
- curiosidades científicas

Todo desarrollado usando únicamente tecnologías web básicas:

- HTML
- CSS
- JavaScript

⚠️ **El proyecto funciona completamente de forma LOCAL**, sin depender de internet.
